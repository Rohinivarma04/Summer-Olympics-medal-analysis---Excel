# 2020 Summer Olympics Medal Analysis

## Project Overview

This project analyzes the medal performance of countries in the
2020 Summer Olympics using Excel.

The dashboard provides insights into Gold, Silver, Bronze, and
Total Medals won by different countries.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers
- Data Visualization

## Key Analysis

- Gold Medal analysis
- Silver Medal analysis
- Bronze Medal analysis
- Total Medal comparison
- Top 10 countries
- Country-wise medal performance
- Rank-based analysis

## Dashboard Features

The interactive dashboard includes:

- KPI cards for medal counts
- Pivot Charts for visualization
- Slicers for interactive filtering
- Top 10 country comparison
- NOC-based filtering
- Rank-based analysis

## Project Outcome

The dashboard makes it easier to compare Olympic medal
performance across countries and identify the top-performing
countries using interactive visualizations.
